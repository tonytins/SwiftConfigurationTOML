# Swift Configuration TOML

This is a TOML parsing and serialization library written in pure Swift for Apple's [configuration library](https://github.com/apple/swift-configuration). It began from my [SimsCraft](https://github.com/tonytins/SimsCraft) project (which is vibe coded due to the sheer scale of it all) as a drop-in replacement for [`swift-configuration-toml`](https://github.com/mattt/swift-configuration-toml) after I was having issues with CTomlPlusPlus.
